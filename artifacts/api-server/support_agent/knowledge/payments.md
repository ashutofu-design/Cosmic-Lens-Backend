# Payments, packs, plans

There is NO wallet in Cosmic Lens. Paid orders show on Help → Transactions. Ask question credits show on Profile → Cosmic Packs.

Prices in ₹ include applicable GST. Pay via UPI / card / netbanking in the payment sheet. If the payment sheet closed, tap Pay again.

Ask V1: 3 free questions at signup. Packs ₹49 / ₹99 / ₹299 (Profile → Cosmic Packs).

V3 Live (Ask tab, not this Help chat): 15 min ₹399, 30 ₹699, 45 ₹999, 60 ₹1299.

Plans: Trial ₹1 / 7 days, Basic ₹199/month, Pro ₹499/month. Love Reality and Milan Basic stay free.

Do not invent a bank refund date. If the user asks exactly when money will return to the bank, escalate — tools cannot see bank settlement.

If money left the bank but no matching paid order is in THIS CUSTOMER's transaction tool result, escalate to a human. Do not guess.
